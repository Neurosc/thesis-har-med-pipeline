# figS03 ribbon-colour previews — SIMULATED DATA, not results

Five SVG mocks of the reworked `figS03` (excluded-subjects FD panel), one per candidate
Set2 ribbon colour: pink, orange, teal, lime, yellow. They exist only to choose a colour
before spending a server run.

**The FD traces are simulated.** Per-frame FD is computed from the fMRIPrep confounds,
which live on the server, so it cannot be rendered locally. Only two things in each panel
are real, taken from `../../results/run_level_fd_summary.tsv`:

| run | % censored | max FD (mm) |
|-----|-----------:|------------:|
| sub-12 ses-02 | 85.8 | 0.869 |
| sub-12 ses-01 | 80.8 | 0.937 |
| sub-26 ses-01 | 56.2 | 1.277 |
| sub-36 ses-02 | 52.1 | 0.785 |
| sub-06 ses-01 | 51.2 | 1.786 |
| sub-08 ses-02 | 50.4 | 4.264 |

Everything else — the shape of each trace, where the spikes fall — is invented. **Do not
read anything into these figures and do not put them in the thesis.**

They also preview the reworked design, independent of colour:

- censoring drawn as a thin ribbon along the bottom axis instead of full-height shading,
  with the FD trace on top at higher z-order, so the signal stays readable;
- y-axis clipped to 2 mm so five of the six runs fill their panels, with sub-08's
  4.26 mm excursion annotated with its true value rather than silently truncated;
- the in-axes "0.3 mm" text dropped — the legend already identifies the threshold line.

Delete this directory once a colour is chosen and the real figure is regenerated by
`../../scripts/excluded_subjects_panel.py` on the server.
